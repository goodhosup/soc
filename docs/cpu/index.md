!!! basic "CPU 구성 표기 미리 보기"
    칩셋 사양표의 `1 + 3 + 4`, `2 + 6` 같은 숫자는 **클러스터별 코어 개수**입니다. 보통 가장 빠른 코어부터 적습니다.

    1. **프라임(최고 성능) 코어** — 단일 스레드 성능을 담당. 1–2개, 가장 높은 클럭
    2. **성능(중간) 코어** — 대부분의 앱 작업. 여러 개
    3. **효율(작은) 코어** — 백그라운드·저부하 작업. 최근에는 개수가 줄거나 없는 구성도 등장

    예를 들어 `1 + 3 + 4`는 프라임 1개, 성능 3개, 효율 4개입니다. 같은 종류의 코어라도 클럭을 다르게 묶어 `1 + 2 + 2 + 3`처럼 네 그룹으로 표기하기도 합니다.
