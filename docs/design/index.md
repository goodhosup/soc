# 설계와 제조

이 섹션은 SoC가 **사양서 한 장에서 출발해 스마트폰에 실리는 양산 칩이 되기까지**의 과정을 다룹니다. 앞 장들이 CPU·GPU·메모리 같은 블록이 "무엇을 하는가"를 설명했다면, 여기서는 그 블록들을 누가 만들고, 어떻게 한 다이에 묶고, 어떻게 틀린 곳이 없는지 확인하며, 어느 공장에서 어떤 비용으로 찍어 내고, 어떻게 포장하고 시험하는지를 봅니다. 플래그십 SoC 한 개는 수백 명 이상의 엔지니어가 여러 해에 걸쳐 만드는 결과물이며, 그 일정과 비용의 대부분은 설계 자체보다 **검증과 제조**에 들어갑니다.

| 페이지 | 핵심 질문 |
|---|---|
| [SoC 설계 흐름](flow.md) | 사양서에서 테이프아웃까지 어떤 단계를 거치고, 각 단계에서 무엇을 확인하나? |
| [IP와 통합](ip-integration.md) | 어떤 블록을 사 오고 어떤 블록을 직접 만들며, 수십 개 IP를 어떻게 한 칩으로 엮나? |
| [검증과 에뮬레이션](verification.md) | 칩을 만들기 전에 어떻게 버그를 찾고, 소프트웨어는 어떻게 미리 돌려 보나? |
| [파운드리와 공정](foundry.md) | TSMC·삼성·Intel 파운드리는 무엇이 다르고, 웨이퍼 가격과 수율은 칩 원가를 어떻게 정하나? |
| [패키징](packaging.md) | 다이를 어떻게 포장해 보드에 붙이고, 칩렛과 적층은 왜 등장했나? |
| [시험과 양산](test.md) | 수많은 칩 가운데 불량을 어떻게 걸러 내고, 같은 칩을 어떻게 등급으로 나누나? |

!!! basic "SoC 한 개가 만들어지는 길 미리 보기"
    SoC가 만들어지는 과정은 건물을 짓는 일과 비슷합니다.

    1. **설계** — 무엇을 지을지 정하고(사양), 방 배치를 그리고(아키텍처), 상세 도면을 그립니다(RTL·물리 설계).
    2. **검증** — 공사를 시작하기 전에 도면에 틀린 곳이 없는지 시뮬레이션과 모형으로 확인합니다.
    3. **제조** — 도면을 공장(파운드리)에 넘기면(테이프아웃) 웨이퍼 위에 수백 개의 칩이 한꺼번에 만들어집니다.
    4. **패키징과 시험** — 웨이퍼를 잘라 하나씩 포장하고, 제대로 동작하는지 시험해 등급을 매겨 출하합니다.

    건물과 다른 점은 **한 번 지으면 고칠 수 없다는 것**입니다. 마스크 한 벌을 다시 만드는 데 큰 비용과 몇 달이 들기 때문에, 전체 일정의 상당 부분을 검증에 씁니다.

!!! tip "다른 섹션과의 연결"
    공정 이름과 트랜지스터 구조는 [공정 노드와 미세화](../basics/process-node.md), 다이 면적과 수율의 기본 계산은 [성능·전력·면적 (PPA)](../basics/ppa.md), DRAM을 SoC 위에 쌓는 PoP는 [패키지와 PoP](../memory/packaging.md), 칩 안의 전원 구획은 [파워 도메인과 게이팅](../power/power-domains.md), 최신 공정 경쟁은 [2nm 세대와 GAA 경쟁](../next/2nm.md)에서 다룹니다.
