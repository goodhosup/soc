## 페이지 구성

모든 기술 페이지는 다음 순서로 구성됩니다.

!!! spec "규격 · 세대"
    관련 표준(Arm 아키텍처 버전, JEDEC LPDDR·UFS, MIPI, AMBA 등)과 해당 기능이 처음 들어간 칩셋 세대. 확실하지 않은 세대 정보는 적지 않습니다.

!!! basic "한눈에 보기"
    <span class="lv lv1">기초</span> 개념과 비유. 수식이나 코어 이름 없이 "무엇이고 왜 필요한가"만 설명합니다.

**본문** <span class="lv lv2">중급</span> 구조, 파라미터, 표, 블록 그림, 동작 순서. 헤딩 옆 배지로 난이도를 표시합니다.

??? expert "전문가 노트"
    <span class="lv lv3">전문가</span> 마이크로아키텍처, 수식, 설계 트레이드오프, 커널 코드 위치, 실무에서 자주 헷갈리는 점.
    기본으로 접혀 있으니 필요할 때 펼쳐 보세요.

해당하는 페이지에는 끝에 **칩셋 비교** 표가 붙고, 마지막은 항상 **관련 페이지** 목록입니다. 레지스터·커널 설정·명령 이름은 `schedutil`, `operating-points-v2`, `/sys/devices/system/cpu`처럼 코드 글꼴로 씁니다.

## 용어 몇 가지 먼저

| 용어 | 뜻 |
|---|---|
| SoC (System on Chip) | CPU, GPU, 메모리 컨트롤러, 각종 가속기와 입출력을 한 개의 실리콘 다이에 모은 칩 |
| AP (Application Processor) | 스마트폰에서 운영체제와 앱을 돌리는 프로세서. 지금은 모뎀까지 품은 SoC와 거의 같은 뜻으로 씀 |
| 칩셋 (chipset) | 원래는 함께 쓰는 칩 묶음(SoC + PMIC + RF 칩 등)을 뜻했지만, 일상에서는 SoC 자체를 가리킴 |
| IP (Intellectual Property) 블록 | 다른 회사가 설계해 라이선스로 파는 회로 설계. 예: Arm CPU 코어, GPU, 인터페이스 PHY |
| 다이 (die) | 웨이퍼에서 잘라 낸 실리콘 조각 한 개. 패키지 안에 들어가 칩이 됨 |
| 공정 노드 | 칩을 만드는 제조 기술 세대. "3nm" 같은 이름은 실제 치수가 아니라 세대 이름에 가까움 |
| 파운드리 (foundry) | 남이 설계한 칩을 위탁 생산하는 회사. TSMC, 삼성 파운드리 등 |
| 팹리스 (fabless) | 공장 없이 설계만 하는 회사. Qualcomm, MediaTek, Apple 등 |

!!! tip "SoC와 칩셋, AP는 거의 같은 뜻으로 쓰입니다"
    "스냅드래곤 칩셋", "엑시노스 AP", "Apple SoC"는 모두 같은 종류의 물건을 가리킵니다. 이 책에서는 기술 용어로 **SoC**를 기본으로 쓰고, 제품을 부를 때는 제조사가 쓰는 이름(모바일 플랫폼, 프로세서)을 따릅니다.

자세한 구조는 [SoC란 무엇인가](what-is-soc.md)와 [성능·전력·면적 (PPA)](../basics/ppa.md)에서 다룹니다.
