# 최신 동향

이 섹션은 스마트폰 SoC를 둘러싼 **지금 움직이고 있는 흐름**을 다룹니다. 트랜지스터 구조가 FinFET에서 GAA로 넘어가는 2nm 세대, 스마트폰 SoC 기술이 노트북과 자동차로 넓어지는 흐름, 그리고 Arm 중심의 생태계에 새로 등장한 오픈 ISA인 RISC-V입니다. 이 장의 내용은 빠르게 바뀌므로, 각 페이지는 **이 페이지 기준 시점(2026년 하반기)의 발표·보도**를 바탕으로 쓰고 확정되지 않은 내용은 "보도 기준", "계획"으로 구분합니다.

| 페이지 | 핵심 질문 |
|---|---|
| [2nm 세대와 GAA 경쟁](2nm.md) | TSMC N2·삼성 SF2·Intel 18A는 무엇이 다르고, 후면 전력 공급과 High-NA EUV는 왜 중요한가? |
| [Arm PC와 노트북 SoC](arm-pc.md) | Apple M 시리즈와 Snapdragon X는 스마트폰 SoC와 무엇이 다르고, x86 앱은 어떻게 돌리나? |
| [차량용 SoC](automotive.md) | 콕핏과 ADAS SoC는 무엇이 다르고, ISO 26262·AEC-Q100은 칩 설계를 어떻게 바꾸나? |
| [RISC-V의 부상](riscv.md) | RISC-V는 이미 스마트폰 SoC 어디에 들어 있고, 앱 프로세서가 되려면 무엇이 남았나? |

!!! basic "이 장을 읽는 법"
    네 페이지는 모두 "스마트폰 SoC에서 배운 것이 어디로 확장되는가"라는 질문으로 이어집니다.

    1. **공정** — 같은 면적에 더 많은 트랜지스터를 넣는 방법이 구조 자체를 바꾸는 단계에 왔습니다.
    2. **노트북** — 스마트폰의 저전력 설계를 그대로 키우되, 메모리 버스와 전력 한도를 넓힙니다.
    3. **자동차** — 성능보다 "고장 나도 안전한가"와 "15년을 버티는가"가 먼저입니다.
    4. **ISA** — CPU 명령어 집합 자체를 라이선스 없이 쓸 수 있게 되면 무엇이 달라지는지 봅니다.

    공정 이름과 미세화의 기초는 [공정 노드와 미세화](../basics/process-node.md)를 먼저 읽으면 편합니다.

!!! tip "다른 섹션과의 연결"
    공정의 기초는 [공정 노드와 미세화](../basics/process-node.md)와 [파운드리와 공정](../design/foundry.md), Arm ISA와 자체 설계 코어는 [Arm 아키텍처](../cpu/arm-architecture.md)와 [자체 설계 코어](../cpu/custom-cores.md), 차량용 SoC의 하이퍼바이저는 [가상화](../security/virtualization.md)에서 다룹니다. 세대별 칩셋의 공정은 [칩셋 세대 인덱스](../reference/chipset-index.md)에 모읍니다.
